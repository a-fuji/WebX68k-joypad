# 海賊王ゲーム

X68000 / Human68k用の固定画面シューティングの最小実装です。非公式ファンゲームとして、ルフィ風の自作ドット絵、百獣海賊団の手下風の敵、ビッグ・マムとカイドウの2ステージを扱います。タイトルはユーザー提供画像を変換して使用します。

矢印キーまたはジョイスティックの8方向で移動し、Z / TRG1でショット、X / TRG2で全体攻撃を出します。全体攻撃ではゾロ・サンジ風の援護が交互に登場します。Rで最初から再開、ESCでHuman68kへ終了します。ゲームオーバーと全ステージクリア後もZ / TRG1で再開できます。

| ファイル | 役割 |
| --- | --- |
| `PIRATE.S` | ゲームループ、入力、当たり判定、ページ切替、タイトル表示 |
| `STATE.INC` | MCPで読み取る`P68KSTAT`構造体のフィールド位置 |
| `ART.INC` | 自作フォント・キャラクターのパターンとパレット |
| `SOUND.INC` | IOCSによるオリジナルFM曲 |
| `BUILD.BAT` | Human68k上でのHAS060・HLK実行 |

実行環境のWebX68kとは別のソースツリーです。MaidLandのソース、画像、音源、ゲームデータは含めません。外部ライブラリ、XSP2、Z-MUSICの常駐ドライバは不要です。
