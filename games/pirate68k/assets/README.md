# グラフィック素材

`characters-source.png`と`backgrounds-source.png`は、ユーザーが承認した見下ろしゲーム画面案を参考に、2026-10-24に組み込み画像生成ツールで制作したPNG。MaidLandの画像・音楽・ゲームデータは使用していない。非公式ファンゲーム用の素材である。

- `characters-source.png`: 1448×1086、RGBA。後ろ向きルフィ4ポーズ、ザコ2ポーズ、ゾロ、サンジ、ビッグ・マム、カイドウ、自弾、敵弾。生成画像の区画は厳密な等分ではないため、`graphics.py`の`REGIONS`が切出し範囲の正本。
- `backgrounds-source.png`: 1774×887、RGB。左半分が港、右半分が要塞。キャラとHUDを含まない背景。

`tools/pirate68k/graphics.py`で実寸へ縮小・減色し、XSP用PCGとパレットを生成する。透過しきい値を適用し、アニメーションの系列内では同じ縮小率を使う。背景は256色、キャラクターは各15色＋透明色。斬撃・炎の軌跡は同じ変換スクリプト内のマスクから生成する。元PNGは保持し、生成物を`_local/pirate68k/graphics/`へ出力する。

生成時の指示:

- キャラクター: 承認済み画面を絵柄の参照とし、透明背景の4列3行アトラスを作る。ルフィは常に後ろ向きで帽子・赤い上着・青いズボンを示し、待機・左移動・右移動・上向きパンチを描く。ザコは下向きの角と棍棒、ボスは斜め上から見た全身。通常キャラ32×32、ボス96×96への変換を意識した明確な輪郭と少数色。区画の間を透明にし、文字や床を描かない。
- 背景: 同じ画面案からキャラクター・影・弾・HUD・ラベルを除き、2枚の正方形を横に並べる。青灰色の港の石畳と紫灰色の要塞。海・溶岩・柵・瓦礫は左右の縁に寄せ、中央を移動可能な低彩度の床にする。地平線や消失点を描かない。

画像生成モデルによる元PNGの再生成は同一バイト列を保証しない。ゲームの再現ビルドにはこの保存済みPNGを使う。変換器は元画像のSHA-256とタイル数を`graphics.json`へ記録する。
